# Your career data (`my/`)

This is the career-ops **data root** (see `../.career-ops-data` and `../START_HERE.md`).

| Folder / file | Purpose |
|---------------|---------|
| `output/resumes/YY-MM-DD/` | **CVs to submit** — `DD-{Company}-Resume.pdf` (by generation date) |
| `output/archive/` | Old working files |
| `reports/` | Evaluation reports |
| `data/` | Tracker, scan history, pdf-index |
| `cv.md` | Master CV |
| `documents/` | Source resumes |
| `jds/` | Saved JDs |
| `config/profile.yml` | Profile |
| `modes/_profile.md` / `_custom.md` | Targeting + house rules |

Root symlinks (`../cv.md`, `../output`, …) point here so scripts/agents keep working.
